# Project Brief: AI Technical Interview System

## Project Overview
**Goal:** Develop an MVP web application that enables an AI agent to conduct technical interviews with Globant workers (Globers) applying for specific positions within client accounts (Northwind Media, Globex Studios, etc.).

## Core Value Proposition
- **Automated Technical Screening:** Replace manual initial technical interviews with AI-driven conversations
- **Objective Assessment:** Focus exclusively on quantifiable technical attributes
- **Standardized Process:** Ensure consistent evaluation criteria across all interviews
- **Scalable Solution:** Handle multiple interviews simultaneously without human resource constraints

## Project Scope

### In Scope
- AI-conducted verbal interviews in conversational format
- Technical skills assessment based on Job Descriptions and CVs
- Structured feedback generation with 1-5 ranking system
- Interview scheduling and management system
- User role management (Admin, Recruiting Analyst, Candidate)
- CRUD operations for all core entities
- File upload capabilities for CVs and Job Descriptions
- Unique time-sensitive interview links
- Filterable lists for interviews and candidates

### Out of Scope
- Subjective behavioral or conduct-related criteria evaluation
- Advanced search capabilities or custom reporting
- Integration with external calendar systems
- Real-time sentiment analysis
- Complex data visualization
- Export functionalities (CSV, PDF)
- Advanced user authentication methods (SSO, MFA)

## Success Criteria
1. **Functional MVP:** Complete interview workflow from scheduling to feedback generation
2. **Technical Accuracy:** AI correctly evaluates quantifiable technical skills
3. **User Experience:** Intuitive interfaces for all user roles
4. **Data Integrity:** Secure storage and management of interview data
5. **Scalability Foundation:** Architecture supports future enhancements
